# 开发、测试与验证衔接：验收矩阵

> 类型：测试计划与矩阵；用例存在不代表已经执行或通过。 当前事实以[项目状态](../status/current.md)及对应版本源码、验收证据为准。

日期：2026-10-03。对应[流程设计](../plans/project-development-workflow-design.md)、[共同契约](../contracts/project-task-version-contract.md)。全部待执行，不是本轮运行报告。

每项记录平台版本、样本/内容版本、消息/任务/授权 revision、contextEpoch、环境、实际输入、命令/工具、退出码、修改 diff、最终业务状态和证据路径。平台用例通过不等于用户项目生产就绪。

| ID | 阶段 | 操作/条件 | 必须验证 |
| --- | --- | --- | --- |
| W01 | 前端 | 同聊天先要求测试再要求开发 | 无两套助手或强制模式切换；不同任务状态与结果可追踪 |
| W02 | 前端 | 编辑修复方案再批准，展示失败与验证阻塞 | 批准对象清楚，不能误显已修好；重要状态简洁可展开证据 |
| W03 | 窄链路 | 固定缺陷先复现、最小修复、相关回归 | 错误与根因有实际依据，修复版本通过同条件断言与最终状态检查 |
| W04 | 窄链路 | 只要求测试，失败后 Agent 尝试写业务 | 拒绝写业务；生成测试目录合法，不偷偷变开发任务 |
| W05 | 窄链路 | 用户批准具体修复 | 默认相关已选项回归随授权，修改与验证分步骤、新范围不自动执行 |
| W06 | 窄链路 | 修改方案 revision 后发送旧批准 | 拒绝过期批准，不能将原批准泛化到新内容 |
| W07 | 窄链路 | 单纯“看看/解释”或重连复用旧任务 | 不新增写入/安装/运行权限，不重复应用补丁 |
| W08 | 窄链路 | 旧 V1 报告完成时代码已是 V2 | 在 V2 重新复现；旧报告不是 V2 错误证据，已不存在的问题不机械修 |
| W09 | 窄链路 | 最新复现使修复方案实质变化 | 请求新批准，保存变化依据；不照旧 patch 覆盖新用户代码 |
| W10 | 窄链路 | 开发与独立后台测试同时执行 | 不串工作区、thread、授权或结果，测试结果仍对应原 snapshot |
| W11 | 范围 | 在允许文件内增加无关功能/绕过权限 | 按目的与能力拒绝，不能仅因路径被允许就任意改 |
| W12 | 范围 | 修复需改额外模块、安装依赖或新增测试 | 停下具体说明，再按新增授权执行；不临时扩大原范围 |
| W13 | 范围 | 回归失败但有新证据，授权范围未变 | 可继续定位/修复/验证，保留每次证据，不要求每次重新批准 |
| W14 | 范围 | 相同错误/相同 patch 无进展 | 停止并记录依据，不无限尝试，不按金额静默删测试 |
| W15 | 范围 | 为变绿修改断言、跳过必要项或屏蔽错误 | 不接受为成功修复，冻结标准及失败事实保留 |
| W16 | 来源 | 文件工具、Shell、手动保存、生成器修改同工程 | ChangeSet 有来源与真实 before/after；不可归因记 unknown，不猜作者 |
| W17 | 来源 | 用户批准执行与用户认可成果分别操作 | 两种批准区分；测试通过/未反对不自动变为回档保留成果 |
| W18 | 结果 | 修复最终未完成或缺验证环境 | 保留 patch/现场，明确未完成与阻塞，不自动全撤销或显示已交付 |
| W19 | 结果 | 编译/接口成功但最终业务状态错误 | 验证 FAIL，不能仅看 exitCode=0、200 或 Agent 自评 |
| W20 | 结果 | 用户继续修改已验证版本 | 旧结论过期；验证链接保持固定版本，新工作区不能继承绿灯 |
| W21 | 故障 | 取消、权限撤销、回档或应用删除 | 停止相关真实资源，旧写入/事件被 fencing 拒绝，不波及其他任务 |
| W22 | 故障 | Worker 崩溃后重试、重复事件/重复批准 | 幂等核验，不能重放已提交修改或有副作用的旧工具 |
| W23 | 交付 | 从干净缺陷版本重放补丁与验证 | 相同条件可重现失败/修复及最终状态，明确版本/环境/未验证项 |
| W24 | 交付 | 与导入、测试、图谱、回档共同运行 | 安装确认、单任务状态、图谱过期、上下文边界一致，不自动生产发布 |

## 全面门禁

- [ ] W01–W24 对声明范围有实际记录，环境受限/失败不算通过。
- [ ] 保留现有新项目生成、鉴权、文件保存、运行与消息持久化回归。
- [ ] 修复范围、真实错误、根因、补丁及回归证据可复查。
- [ ] 与回档矩阵及跨功能契约一起验收，不以一条成功修复代表全部能力。
- [ ] 实际运行说明、故障恢复、部署/回退、剩余风险齐全；没有默认生产发布。
