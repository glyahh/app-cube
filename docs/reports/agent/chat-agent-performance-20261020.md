## 实现

- 聊天按消息复用展示分组与 Markdown，缓存随消息释放；内容变更显式递增修订号，避免渲染期间整段 JSON 序列化。同长度思考更新、工具原位替换、流式结束与取消可使缓存失效；未变化阶段保留子组件 props 身份，展开状态和安全清洗保持原有行为。
- 独立审查最多两个常驻进程，预热 SDK 后逐请求重新构建无工具调用；不保留上一次审查对话或结果。保留一次性 CLI。Java 复核请求身份、协议字段与原有对象哈希；Python 75秒看门狗、Java 90秒总期限以及原有输入输出边界保持。配置更新换代，停止未确认继续占槽；不重放失败请求、不降级批准。
- 主模型新增脱敏阶段计时，关联 `runId/callId/attempt`；覆盖 TCP/TLS、发送尝试、响应头、有效流片段、最长间隔、结束及重试原因。单次/累计 token 分列，usage 缺失明确标记；不记录请求正文、地址、凭据或模型文本。代理回退保持同一计时身份，不改变回退策略。
