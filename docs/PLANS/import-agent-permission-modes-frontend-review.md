## 审核入口

开发服务器运行时打开：`http://127.0.0.1:5173/permission-preview.html`。

若前端未启动，在 `ai-generate-code-frontend` 执行 `npm run dev`，使用实际端口。无需登录、后端、数据库或 Docker。

- 默认手动批准：点击发送，依次确认普通源码、README、检查命令，最后单独整批确认。
- 自动批准：由 AI 审查待执行操作，非高风险直接放行，高风险留给用户确认。演示中普通源码为非高风险，README 和工程命令为高风险；最终候选单独审查，含高风险仍整批确认。
- 自由发挥：选择后直接保存，不显示二次确认弹窗；保存成功后合法操作和候选合入均显示策略自动批准。保存失败仍保留原模式。
- 等待批准时模式锁定；拒绝停止整轮。安全预览和最终差异按需展开，只渲染纯文本。
- 工具审批新增“本会话批准同类请求”，位于“仅批准本次”右侧，手动与自动模式均可用。成功后当前页会话内跨轮记住相同动作、风险与目标范围；普通文件限同目录，高风险文件限同文件，命令限相同命令详情。失败或对象失效不记住。普通说明与单次批准提示移除，对象名放在标题右侧淡化；高风险原因保留。
- 输入区选择栏：权限为贴合文字宽度的无箭头胶囊，右侧模型和思考力度随文字自适应宽度，力度保留图标。模型支持搜索，选项显示提供方和当前选中标记；思考力度分低、中、高，附简短说明。发送按钮固定在操作栏右侧，窄屏只让选择栏内部必要换行，任务进行时三个选择器均锁定。

优先审核：输入区下拉的位置与宽度、三个标签、工具卡片和最终确认的区别、窄屏按钮和间距。问号帮助入口与自由发挥确认弹窗已按用户要求移除。

### Codex 风格统一

整体会话改为中性白灰、细线分区，移除卡片套卡片和会话开始后的重复引导。审批区融入消息流：标题、对象、风险说明、可展开纯文本差异、授权范围和紧凑操作栏依次排列；不再使用窄屏满宽大按钮和黄色大标签。文件差异用浅红/浅绿区分删除和新增，同时保留符号与原始文本。模型与力度选择栏保留，项目侧栏和输入区同步统一样式。

整批审批文案改为“请核对以下候选修改，尚未合入源码”，移除“独立校验通过”的演示声明；真实校验和合入仍未接线。

工具会话批准不替代整批确认；仅批准本次不会记住后续请求。同类授权在当前页内跨轮和模式切换有效，刷新/重建页面清空，没有正式服务端授权登记；演示命令详情并非真实脚本摘要证据。

## 实现边界

新增独立 HTML 与 `src/preview/import-permissions/`，不修改生产 AppChatView、个人偏好、正式路由或传输。

页面使用隔离数据演示交互。页面中的 AI 风险审查、独立校验、批准、停止、清理和合入结果不是实际业务结果；本轮没有调用真实 AI，也未执行任何文件修改或工程命令。没有持久化页面授权，不使用 localStorage。刷新重新进入默认手动批准，不能作为服务端恢复已完成的证据。

模型选项 GPT-5.2、Claude Sonnet 4.5、DeepSeek Chat 及其思考力度支持情况仅为 UI 示例，不代表真实配置或供应商能力结论。默认 GPT-5.2 / 中；不支持力度的示例模型显示“不支持”并禁用力度选择。模型和力度未接入正式请求或持久化。

故障场景由入口装配参数或单元测试注入，产品页面无测试开关。演示支持保存失败、策略冲突、批准失败、对象失效、硬禁止及合入失败。

后端仍未实施：服务端 AI 风险审查、策略 GET/PUT、policyRevision CAS、权限票据、消费、候选决定、Java/Python 门禁、数据库迁移、刷新找回、SSE/WS、等待心跳和恢复。正式前端接线也待后端提供权威状态。真实授权系统尚未交付。
