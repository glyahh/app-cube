# 四项功能：跨功能一致性验收

日期：2026-10-03。对应[共同契约](./project-task-version-contract.md)。全部待执行，不是实现或测试完成记录。

每项记录四功能涉及的 app/task/message/snapshot/contextEpoch、实际资源状态、授权与证据归属，以及最终文件、数据库/业务状态和真实模型请求。

| ID | 联动场景 | 必须验证 |
| --- | --- | --- |
| X01 | 同名文件夹/仓库/不同分支多次导入 | 独立 app，不覆盖；GitHub/Gitee、Token、来源 commit 与后续内容版本分开 |
| X02 | 导入后图谱默认后台生成 | 不自动安装/运行；图谱只读且不阻塞导入完成，开关/失败规则正确 |
| X03 | 上传保留依赖目录、排除敏感配置 | 导入过滤不等于图谱深入第三方库或模型可读敏感配置，runtime 依赖就绪需验证 |
| X04 | 手动目录/服务多选后准备测试 | 候选不是运行成功；测试环境独立，当前预览/成功服务不会被验收 runner 覆盖 |
| X05 | 手动保存、Agent 写、测试/图谱同时建快照 | 写入闸门一致，发布的每份快照完整；不得借知识文件限额生成恢复/测试截断副本 |
| X06 | 测试与图谱进行中继续开发 | 两者旧轮按旧 snapshot 结算，标过期；当前任务不因旧消息/结果混写 |
| X07 | 前端关自动同步或关 app 图谱 | 前者允许当前轮，后者取消专属任务；不取消主开发/测试或其他 app |
| X08 | 测试新风险与修复建议 | 用户批准新增范围，修复独立授权；标准冻结，未测风险不隐藏 |
| X09 | 旧版缺陷报告批准修复 | 最新复现、方案变化重确认，相关回归绑修复版；图谱关系过期不能作为当前事实 |
| X10 | 所选测试全绿、必要项未选/环境缺失/人工未确认 | 完整列表和门槛缺口可见，不能综合高分或用户打勾假成程序验收 |
| X11 | 开发/测试/图谱/后台容器运行中回档 | 所有相关资源先停止核验、旧资格撤销；只恢复代码/context，不偷偷还原数据库 |
| X12 | 回档保留认可代码但删除错误过程 | 最终文件重新读为当前事实；旧摘要、工具、store、图谱推断、报告零进新请求 |
| X13 | 内容 hash 相同、epoch 不同 | 静态事实缓存重新资格化；推断、测试失败摘要和旧 checkpoint 不随 hash 复活 |
| X14 | 旧报告主动保存在项目，回档后 Agent 全仓库搜索 | 人类可只读，当前 Agent 不通过 Shell/文件/索引/报告工具读撤销内容 |
| X15 | 用户换 Token/删 Token/撤销应用权限 | 新导入使用新值；删 Token 取消关联未完成导入；已完成 app 不误删，权限撤销旧任务资格失效 |
| X16 | 断流、重连、冷启动、旧 taskKind/协议 worker | 后台测试可查询、不盲取消；合法 historyTail 与能力协商，旧 worker 不默认可写执行 |
| X17 | 崩溃、孤儿容器、迟到事件和重复请求 | 幂等与真实停止确认，不能跨 app/run 杀新任务；半恢复新旧状态不被读取 |
| X18 | 用户清理回档点、临时证据到期与下载/回档并发 | 有效回档点不自动到期/按数量淘汰；临时报告过期不删除回档所需材料；不清引用/在用/唯一恢复依据，不删用户代码；主动清理影响明确，已缺证据不再宣称可回放 |
| X19 | 模型故障、图谱额外重试失败、Docker 不可用 | 明确失败，无默认静态图/宿主 Shell/模型自评降级，无假成功传播 |
| X20 | 干净导入基线重放开发、测试、图谱与回档 | 原项目/Git 历史不变，所有结果归属一致，最终代码/context/业务状态有真实证据 |

跨功能通过条件是本期承诺场景逐项完成，不是一个全局 succeeded 状态。没有运行这些场景，不能宣称四项可用或企业级交付。
