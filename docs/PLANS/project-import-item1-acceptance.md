本期固定样本在 `src/test/resources/import-acceptance/`，不能用其中一份推断其他组合已经能运行：

- `vue`：npm 脚本识别。样本没有写端口。沙箱镜像不保证有 Node，因此这组只作为识别样本，不作为已运行的 Vue 服务。

- `static-page`：只有 `index.html`，没有启动命令，也不编造地址。
- `dual`：两个写明端口的进程，前端 `4173`，接口 `8080`。这是双服务运行样本，不是 Vue 或 Spring 已经跑起来的证据。

限额沿用执行器：内存钉住 `memory.swap.max=0`、CPU、进程数、耗时、输出字节、副本字节上限。副本上限是执行器自己数字节，不是内核磁盘配额。未写端口的任务保持无网络，不编造地址。写明端口时只发布 `127.0.0.1`，对本机地址请求成功后才算就绪。
